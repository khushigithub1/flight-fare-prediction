Project Info

About Flight Fare

Everything you need to know about this project and how it works.

What is this?

FarePilot is a machine learning web application that predicts domestic Indian flight fares based on historical ticket data. It uses a trained Random Forest / XGBoost model to deliver reliable estimates in seconds.

How it works

  1. Data collected from multiple airline booking portals.
  2. Feature engineering: date, duration, stops, airline encoding.
  3. Model trained and validated using cross-validation.
  4. Live predictions served via Flask web API.
Python Scikit-learn XGBoost Flask Pandas NumPy
